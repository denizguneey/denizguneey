# Deniz Güney

PhD student in Mathematics · Gazi University · Ankara, Türkiye

Research interests include graph theory and its computational and cryptographic applications, with an emphasis on exact computation for exploring mathematical structures. Currently building foundations in machine learning and computer vision.

## Selected projects

**[invariant-twins](https://github.com/denizguneey/invariant-twins)**
Interactive, exact-arithmetic laboratory for graph-invariant fingerprints and reproducible non-isomorphic witnesses; verified over all 261,080 connected graphs on 9 vertices.
*Python · NetworkX · Streamlit · MIT license*

**[Use-of-directed-graphs-in-cryptology](https://github.com/denizguneey/Use-of-directed-graphs-in-cryptology)**
Modular text-encryption demonstration using adjacency, distance, or Laplacian matrices derived from directed graphs.
*Python · NumPy · SymPy*

**[eulercodelab-data](https://github.com/denizguneey/eulercodelab-data)**
Local-first collection of Project Euler problem statements, Python solutions, and associated visual resources for EulerCodeLab.
*Python · Markdown · image resources*
